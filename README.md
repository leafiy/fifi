# Fifi

Fifi is a fast, low-resource clipboard history manager for macOS. It lives in the menu bar and gives you a flat, searchable history without folders, clutter, or a heavy background footprint.

## Highlights

- Captures text, rich text, links, images, colors, and file references
- Opens a quick picker at the current mouse position with `⌘⇧V`
- Searches clipboard content, file names, paths, and source apps
- Deduplicates repeated content and moves reused items to the top
- Pins important entries and automatically cleans up older history
- Filters by content type, source app, and date
- Includes favorites, recent, and frequently used views
- Supports Quick Look, image previews, color previews, and useful copy actions
- English and Simplified Chinese interface

## Privacy and Control

- Clipboard history, settings, and Quick Share credentials are stored locally as plaintext
- Password-manager content is ignored
- Sensitive-content detection can skip or automatically remove selected items
- Private mode keeps new captures in memory only
- Per-app rules let you exclude apps from recording

## Performance

Fifi uses a paginated local history and lazy-loaded previews, so a large clipboard archive stays responsive without loading everything into memory.

## System Requirements

macOS 14 or later.
